# C 题题解（Password）

## 1. 问题转化
设模数 `M = K + 1`。

初始是 `A[i]`，目标是 `P[i]`，所以位置 `i` 还需要被加的次数（模 `M`）是：

`d[i] = (P[i] - A[i] + M) % M`。

一次操作选区间 `[l,r]`，等价于让该区间每个点都 +1（mod `M`）。

## 2. 差分视角
令

- `c[1] = d[1]`
- `c[i] = d[i] - d[i-1] (i>=2)`

如果不考虑“模回绕”的优化，最少操作数是：

`S = sum(max(0, c[i]))`

这和普通区间加法的结论一致：`c[i]>0` 表示在 `i` 必须新开这么多段。

## 3. 回绕带来的可优化量
当 `c[i] < 0` 时，可以把它看成一个“代价点”，代价为：

`w = M + c[i]`（因为 `c[i]` 负，所以 `w` 在 `[1, M-1]`）。

当 `c[j] > 0` 时，可以看成一个“收益点”，收益为：

`v = c[j]`。

若把某个历史代价 `w` 和当前收益 `v` 配对，且 `v > w`，就能把答案再降 `v-w`。

所以问题变成：

- 扫描序列
- 负点提供可选代价 `w`
- 正点尝试用历史最小代价去赚利润
- 总利润最大化，答案 `= S - profit`

## 4. 反悔贪心 + 小根堆
用小根堆维护“当前可被替换的最小值”。

扫描 `c[i]`：

1. `c[i] < 0`：把 `M + c[i]` 入堆（一个新代价）。
2. `c[i] > 0`：
   - `S += c[i]`
   - 若堆非空且 `heap.top() < c[i]`，则可获利：
     - `t = heap.top()` 出堆
     - `profit += c[i] - t`
     - 把 `c[i]` 入堆（反悔：以后若出现更大的正点，还能继续替换）

最后输出 `S - profit`。

## 5. 正确性要点
- 每个正点若要配对，配给它的历史代价显然应当选当前最小的（局部最优）。
- 若后面来了更大的正点，替换掉当前最小已选值只会更优，不会破坏可行性（反悔）。
- 小根堆始终维护“到当前位置为止最优可替换集合”，每次替换都做最大增益。
- 因此累计得到的是全局最大利润，答案最小。

## 6. 复杂度
- 每个元素最多入堆出堆一次。
- 总复杂度 `O(n log n)`。
- 空间复杂度 `O(n)`。
