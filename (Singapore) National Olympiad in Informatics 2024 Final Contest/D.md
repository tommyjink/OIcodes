# D. Coins

把所有称量看成一张 DAG：`x -> y` 表示 `x` 比 `y` 轻，因此在任意合法总排序里，`x` 都必须排在 `y` 前面。

## 1. 固定一个拓扑序

先对完整图做一次拓扑排序，得到顺序 `p[1..n]`，并把每个点重编号成它在这个拓扑序里的位置。

对某个前缀图，如果一个点在拓扑序中的位置是 `i`，那么它能出现的位置一定是一个连续区间。

原因很简单：

- 它最早只能被挪到“最靠右祖先”的后面。
- 它最晚只能被挪到“最靠左后代”的前面。

所以只要知道这个点在当前前缀里：

- 最右能卡住它的祖先是谁；
- 最左能卡住它的后代是谁；

就知道它的可行排名区间。区间长度为 `1` 时，这个点的 rank 就被唯一确定了。

## 2. 前缀判定

对某个称量前缀，设：

- `f[i]` 表示在前 `i` 个位置里，最多能“扩张”到哪个拓扑序位置；
- `g[i]` 表示在后缀方向上，最少能“收缩”到哪个拓扑序位置。

通过当前前缀中的边做两次扫描：

- 从左到右维护 `f`；
- 从右到左维护 `g`；

就能判断重编号后位置为 `i` 的点是否已经确定：

```text
f[i] = i 且 g[i] = i
```

这等价于“它的最早位置和最晚位置相同”。

## 3. 分治求最早时刻

答案关于前缀长度具有单调性：一个点一旦被确定，之后加入更多称量也不会再次变得不确定。

因此对答案做分治：

- 在区间 `[L, R]` 里取 `mid`；
- 用前 `mid` 条边计算一次 `f / g`；
- 已经确定的点递归到左半边；
- 还没确定的点递归到右半边。

实现里再配合当前活跃点集与区间传播，把总复杂度压到 `O((n + m) log m)`。

## 4. 复杂度

- 拓扑排序：`O(n + m)`
- 分治：`O((n + m) log m)`

可以通过 `n <= 2e5, m <= 8e5`。
