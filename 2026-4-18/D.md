## 题目描述

Putata 和 Budada 正在组织一个游戏。有 $n$ 名玩家围成一个圆圈而坐。玩家从 $0$ 到 $n-1$ 编号，第 $i$ 名玩家与第 $((i-1)\bmod n)$ 名玩家和第 $((i+1)\bmod n)$ 名玩家相邻。

游戏开始时，第 $i$ 名玩家有 $a_i$ 单位存款，为一个整数。

在游戏的每一轮中，会发生如下事情：Putata 和 Budada 会选择一个**此前从未被选择过**的玩家 $x$，然后玩家 $x$ 会将自己当前存款的一半（向下取整为整数）给他的某一个相邻玩家。注意，每个玩家至多只能进行一次分享操作。

定义 $f(i)$ 为：在进行了若干轮（也可以一轮都不进行）操作之后，编号为 $i$ 的玩家最终**可能拥有的最大存款数**。

请对于每个 $0 \le i < n$，计算 $f(i)$。注意，不同的 $i$ 对应的答案是**相互独立**计算的。

## 输入格式

输入包含多组测试数据。

第一行包含一个整数 $T$（$1 \le T \le 5 \times 10^5$），表示测试数据组数。

对于每组测试数据：

- 第一行包含一个整数 $n$（$1 \le n \le 5 \times 10^5$），表示玩家数量。
- 第二行包含 $n$ 个整数，第 $i$ 个整数为 $a_i$（$0 \le a_i \le 10^9$），表示第 $i$ 名玩家初始的存款数。

保证所有测试数据中，$n$ 的总和不超过 $5 \times 10^5$。

## 输出格式

对于每组测试数据，输出一行 $n$ 个整数，分别表示 $f(0), f(1), \dots, f(n-1)$。

## 输入输出样例 #1

### 输入 #1

```
3

5

1

```

### 输出 #1

```

1000000000
30 37 41 39 34 27 29 26 31 27
```

## 说明/提示

对于每个位置 $i$，你需要单独考虑一种最优操作方案，使得第 $i$ 名玩家最终的存款尽可能大；不同位置之间的最优方案不需要一致。
