## 题目描述

一个正整数多重集 $s$ 被称为一个 **Pong**，当且仅当存在某个正整数 $x$，使得
$s = \{x, x, x\}$。

一个正整数多重集 $s$ 被称为一个 **Chow**，当且仅当存在某个正整数 $x$，使得
$s = \{x, x+1, x+2\}$。

一个正整数多重集被称为一个 **Mahjong**，当且仅当它可以被划分为若干个（可以为 $0$ 个）**Pong** 和若干个（也可以为 $0$ 个）**Chow**。

注意，这里的定义与原本的麻将规则不同。

现在给定 $n$ 个整数 $a_1, a_2, \dots, a_n$。你的任务是计算有多少个区间 $[l, r]$（$1 \le l \le r \le n$），满足多重集
$\{a_l, a_{l+1}, \dots, a_r\}$
是一个 **Mahjong**。

## 输入格式

输入包含多组测试数据。

第一行包含一个整数 $T$（$1 \le T \le 100$），表示测试数据组数。

对于每组测试数据：

- 第一行包含一个整数 $n$（$1 \le n \le 10^5$），表示整数个数。
- 第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$（$1 \le a_i \le 8$）。

保证所有测试数据中 $n$ 的总和不超过 $10^5$。

## 输出格式

对于每组测试数据，输出一个整数，表示满足条件的区间数量。

## 输入输出样例 #1

### 输入 #1

```
5
4
1 1 1 1
6
1 2 3 1 2 3
7
6 5 8 7 6 3 2
8
1 2 1 2 1 2 1 3
9
2 2 4 4 1 1 1 3 3
```

### 输出 #1

```
2
5
1
3
2
```
