## 题目描述

给定一个 $n$ 行 $m$ 列的网格。在第 $i_h$ 行第 $j_h$ 列的格子中有一个洞。其他所有格子都是空格，并且每个格子中都有一只袋鼠。

同样地，袋鼠由键盘上的 `U`、`D`、`L`、`R` 按钮控制。所有袋鼠会根据按下的按钮同时移动。具体来说，对于任意一只位于第 $i$ 行第 $j$ 列格子中的袋鼠，即位于 $(i,j)$ 的袋鼠：

1. 按下 `U`：它会移动到 $(i-1,j)$。
2. 按下 `D`：它会移动到 $(i+1,j)$。
3. 按下 `L`：它会移动到 $(i,j-1)$。
4. 按下 `R`：它会移动到 $(i,j+1)$。

如果一只袋鼠走到了洞所在的格子（即 $i=i_h$ 且 $j=j_h$），或者走出了网格，那么它会从网格中被移除。

问题在于，$i_h$ 和 $j_h$ 的具体值并不知道。你只会得到一个只由字符 `U`、`D`、`L`、`R` 组成的操作序列，以及一个整数 $k$，表示执行该操作序列后，网格中剩余了 $k$ 只袋鼠。

请计算洞的可能位置数量。也就是说，请计算有多少个整数对 $(i_h,j_h)$ 满足：

- $1 \le i_h \le n$，$1 \le j_h \le m$；
- 洞位于 $(i_h,j_h)$；
- 执行给定操作序列后，网格中剩余的袋鼠数量恰好为 $k$。

## 输入格式

有多组测试数据。输入第一行包含一个整数 $T$，表示测试数据组数。

对于每组测试数据：

第一行包含三个整数 $n$、$m$ 和 $k$（$1 \le n,m \le 10^3$，$0 \le k < n \times m$），表示网格大小，以及执行操作序列后网格中剩余的袋鼠数量。

第二行包含一个字符串 $s_1s_2\cdots s_l$（$s_i \in \{\texttt{U},\texttt{D},\texttt{L},\texttt{R}\}$，$1 \le l \le 10^6$），表示操作序列。

保证所有测试数据中，$n \times m$ 的总和不超过 $10^6$，并且所有操作序列的总长度也不超过 $10^6$。

## 输出格式

对于每组测试数据，输出一个整数，表示洞的可能位置数量。

## 输入输出样例 #1

### 输入 #1

```
3
4 5 3
ULDDRR
4 5 0
UUUUUUU
4 5 10
UUUUUUU
```

### 输出 #1

```
2
20
0
```

## 说明/提示

对于第一组样例测试数据，共有 2 个可能的洞的位置。

第一个可能的位置是 $(3,4)$。

第二个可能的位置是 $(4,3)$。
