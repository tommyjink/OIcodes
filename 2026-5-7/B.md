## 题目描述

有一个由整数序列 $a_1, a_2, \cdots, a_n$ 表示的柱状图，长度为 $n$。从左到右第 $i$ 根柱子的高度为 $a_i$，宽度为 $1$。

接下来会对这个柱状图进行 $q$ 次修改。第 $i$ 次修改可以用一对整数 $(x_i, v_i)$ 表示，含义是：将第 $x_i$ 根柱子的高度增加 $v_i$。

在每次修改之后，你需要回答一个询问：如果一场大雨落下，并且把所有低洼处尽可能填满，那么当前柱状图能够接住多少单位的雨水？

更形式化地说，给定一个长度为 $n$ 的整数序列 $a_1, a_2, \cdots, a_n$，第 $i$ 次修改会令 $a_{x_i}$ 增加 $v_i$。每次修改之后，定义：

$$
f_i = \max(a_1, a_2, \cdots, a_i)
$$

$$
g_i = \max(a_i, a_{i+1}, \cdots, a_n)
$$

你需要计算：

$$
\sum_{i=1}^{n} \left(\min(f_i, g_i) - a_i\right)
$$

## 输入格式

输入包含多组测试数据。

第一行包含一个整数 $T$，表示测试数据组数。

对于每组测试数据：

第一行包含一个整数 $n$（$1 \le n \le 10^5$），表示柱子的数量。

第二行包含 $n$ 个整数 $a_1, a_2, \cdots, a_n$（$1 \le a_i \le 10^6$），其中 $a_i$ 表示第 $i$ 根柱子的初始高度。

第三行包含一个整数 $q$（$1 \le q \le 10^5$），表示修改次数。

接下来的 $q$ 行中，第 $i$ 行包含两个整数 $x_i$ 和 $v_i$（$1 \le x_i \le n$，$1 \le v_i \le 10^6$），表示第 $i$ 次修改会将第 $x_i$ 根柱子的高度增加 $v_i$。

保证所有测试数据中，$n$ 的总和不超过 $10^6$，$q$ 的总和不超过 $10^6$。

## 输出格式

对于每次修改，输出一行一个整数，表示当前柱状图能够接住的雨水总量。

## 输入输出样例 #1

```

### 输出 #1

```
