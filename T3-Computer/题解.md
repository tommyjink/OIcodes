# T3-电脑性能(computer) 题解

## 一、题目分析

本题描述了在机房中对电脑进行性能提升的场景。机房里有 $n$ 台排成一排的电脑，每台电脑都有一个目标性能值 $p_i$。初始时所有电脑性能值为 $0$，技术人员每次可以选择一个连续区间 $[l, r]$，将该区间内所有电脑的性能值提升 $1$ 个单位。要求计算让所有电脑达到目标性能值所需的最少操作次数。

## 二、算法思路

本题可以使用贪心算法来解决。核心思路是通过分析相邻两台电脑的目标性能值，确定为了达到目标性能值所需的额外操作次数。

具体来说，对于相邻的两台电脑 $i - 1$ 和 $i$，若第 $i$ 台电脑的目标性能值 $p_i$ 大于第 $i - 1$ 台电脑的目标性能值 $p_{i - 1}$，那么为了让第 $i$ 台电脑达到目标性能，至少需要额外进行 $p_i - p_{i - 1}$ 次操作；若 $p_i \leq p_{i - 1}$，则不需要额外操作，因为在提升第 $i - 1$ 台电脑性能的过程中，第 $i$ 台电脑可以顺带达到或超过其目标性能。

最终，将每台电脑相对于前一台电脑需要额外增加的操作次数累加起来，就可以得到让所有电脑达到目标性能值所需的最少操作次数。

## 三、代码实现

```cpp
#include<bits/stdc++.h>
#define int long long
#define endl "\n"
using namespace std;
const int N = 1e6;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    int p[N];
    int ans = 0;

    for (int i = 1; i <= n; ++i) {
        cin >> p[i];
        ans += max(0ll, p[i] - p[i - 1]);
    }

    cout << ans << endl;

    return 0;
}
```

## 四、复杂度分析

### 时间复杂度
代码中只需要遍历一次数组，因此时间复杂度为 $O(n)$，其中 $n$ 是电脑的数量。

### 空间复杂度
主要使用了一个长度为 $n$ 的数组来存储每台电脑的目标性能值，因此空间复杂度为 $O(n)$。

## 五、正确性证明

我们可以通过反证法来证明贪心算法的正确性。

假设存在一种更优的操作方案，使得操作次数比我们通过贪心算法得到的结果更少。考虑相邻的两台电脑 $i - 1$ 和 $i$，设 $p_{i - 1}$ 和 $p_i$ 分别为它们的目标性能值。

- 若 $p_i \leq p_{i - 1}$，在提升第 $i - 1$ 台电脑性能的过程中，第 $i$ 台电脑可以顺带达到或超过其目标性能，不需要额外操作。这是显然最优的，因为任何额外的操作都会增加总的操作次数。
- 若 $p_i > p_{i - 1}$，为了让第 $i$ 台电脑达到目标性能，至少需要进行 $p_i - p_{i - 1}$ 次额外操作。如果存在一种方案使得操作次数小于 $p_i - p_{i - 1}$，那么第 $i$ 台电脑将无法达到目标性能，这与题目要求矛盾。

因此，贪心算法得到的结果是最优的。
