# 电脑性能 (computer)

## 题目背景

在一所知名的科技学校里，有一间先进的机房。为了让学生们能更好地进行编程学习和竞赛训练，学校决定对机房里的电脑进行性能提升。

## 题目描述

机房里有 $n$ 台排成一排的电脑，每台电脑都有一个目标性能值。第 $i$ 台电脑最终需要达到的性能值为 $p_i$。

在开始性能提升之前，所有电脑的性能值都为 $0$。学校的技术人员有一种性能提升方案，每次可以选择连续的一段电脑区间 $[l, r]$，然后将第 $l$ 台到第 $r$ 台电脑（包含第 $l$ 台和第 $r$ 台）的性能值都提升 $1$ 个单位。

有一位机智的学生，他很快就想出了一种最优的性能提升策略，能让性能提升操作的次数最少。但他比较忙，没有时间去具体实施，所以想请你帮忙实现这个策略，并计算出最少需要进行性能提升操作的次数。

## 输入格式

输入包含两行。第一行包含一个整数 $n$，表示机房里电脑的数量。

第二行包含 $n$ 个整数，第 $i$ 个整数为 $p_i$，代表第 $i$ 台电脑最终需要达到的性能值。

## 输出格式

输出一个整数，即让所有电脑达到目标性能值所需进行性能提升操作的最少次数。

## 输入输出样例 #1

### 输入 #1

```
5
2 3 4 1 2
```

### 输出 #1

```
5
```
## 说明/提示

**样例解释**

以下是一种可行的最佳方案：
 - 第一次对整个电脑区间 $[1, 5]$ 进行性能提升操作。
 - 第二次对区间 $[1, 3]$ 进行性能提升操作。
 - 第三次对区间 $[2, 3]$ 进行性能提升操作。
 - 第四次对区间 $[3, 3]$ 进行性能提升操作。
 - 第五次对区间 $[5, 5]$ 进行性能提升操作。

**数据范围**
 - 对于 $30\%$ 的数据，$1 \leq n \leq 10$。
 - 对于 $70\%$ 的数据，$1 \leq n \leq 1000$。
 - 对于 $100\%$ 的数据，$1 \leq n \leq 1000000$，$0 \leq p_i \leq 100000$。
