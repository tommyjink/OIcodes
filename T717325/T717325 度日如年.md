# T717325 度日如年

## 题目背景

没放假的时间真是**度日如年**，什么时候才能放假啊！看着日历，小 A 在心里数着日子。**要是现在是休息日就好了**！

## 题目描述

请你帮小 A 算一下从 $2026$ 年某一天起距离最近的休息日还有多少天。其中包括当前这一天，不包括休息日当天。

规定：在本题中，休息日包括法定节假日和双休日，调休不算作休息日。

特别地，如果当天是休息日，那么距离为 $0$ 天。

## 输入格式

输入共一行，包含两个数 $m,d$，表示题目描述中给定的月份和日期。

## 输出格式

输出共一行，一个正整数，表示这一天距离休息日的天数。

## 输入输出样例 #1

### 输入 #1

```
1 2
```

### 输出 #1

```
0
```

## 输入输出样例 #2

### 输入 #2

```
3 24
```

### 输出 #2

```
4
```

## 输入输出样例 #3

### 输入 #3

```
4 1
```

### 输出 #3

```
3
```

## 输入输出样例 #4

### 输入 #4

```
5 8
```

### 输出 #4

```
2
```

## 输入输出样例 #5

### 输入 #5

```
12 31
```

### 输出 #5

```
1
```

## 说明/提示

### 样例解释

对于 $1$ 月 $2$ 日，当天属于元旦假期。

对于 $3$ 月 $24$ 日，距离最近的休息日是 $3$ 月 $28$ 日，为周六。

对于 $4$ 月 $1$ 日，距离最近的休息日是 $4$ 月 $4$ 日，为周六，且属于清明假期。

对于 $5$ 月 $8$ 日，距离最近的休息日是 $5$ 月 $10$ 日，为周日。$5$ 月 $9$ 日为调休日。

对于 $12$ 月 $31$ 日，距离最近的休息日是 $1$ 月 $1$ 日，属于元旦假期。

### 数据范围

保证 $1\le m\le 12$，$1\le d\le a_m$。

其中 $a=\{31,28,31,30,31,30,31,31,30,31,30,31\}$。

小 A 位于中国大陆。
