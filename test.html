斜率优化 DP 终极指南

从代数推导到几何直觉，彻底掌握 Convex Hull Trick

1. 核心瓶颈与破局：代数变形

斜率优化通常用来解决形如以下的一维动态规划方程：

$$dp[i] = \min_{j < i} \{ dp[j] + (A_i - B_j)^2 \} + C_i$$

如果直接暴力枚举 $j$，时间复杂度是 $O(N^2)$。其中最棘手的部分是展开后的交叉乘积项 $-2A_iB_j$。由于它同时包含 $i$ 和 $j$，我们无法直接把它提取到 $\min$ 外面。

破局之法：将其强行转化为一次函数 $y = kx + b$ 的形式！我们把只和 $j$ 有关的项看作变量，把和 $i$ 有关的项看作常数。移项后得到：

$$ \underbrace{dp[j] + B_j^2}_{y} = \underbrace{2A_i}_{k} \cdot \underbrace{B_j}_{x} + \underbrace{dp[i] - A_i^2 - C_i}_{b} $$
  • 纵坐标 $y$：$dp[j] + B_j^2$（仅与 $j$ 有关，是平面上的定点）
  • 横坐标 $x$：$B_j$（仅与 $j$ 有关，是平面上的定点）
  • 斜率 $k$：$2A_i$（对于当前循环的 $i$ 来说，是一个已知的固定常数）
  • 截距 $b$：包含我们梦寐以求的 $dp[i]$。要使 $dp[i]$ 最小，就是要使截距 $b$ 最小！

3. 核心科技：维护下凸壳 (Convex Hull)

并不是所有的点都有资格成为最优解。图中那些“凹进去”的点，无论直线的斜率是多少，都不可能成为第一个被碰到的点。因此，我们需要用单调队列来维护一个“下凸壳”。

剔除废点的数学判别式：
当新点 $C$ 准备入队时，看队尾的两个点 $A$ 和 $B$。
如果 $Slope(A, B) \ge Slope(B, C)$，说明 $B$ 点凹进去了，$B$ 是废点，将 $B$ 从队尾弹出（tail--）。

4. $O(N)$ 降维打击：C++ 终极模板

结合上面演示的“队首弹掉斜率小的找切点”和“队尾弹掉凹陷点维护凸壳”，我们得到了极其优雅的线性代码。

long long Y(int j) { return dp[j] + B[j] * B[j]; }
long long X(int j) { return B[j]; }
// 计算两点之间的斜率 (注意转 double 防精度丢失，或交叉相乘防除零)
double slope(int i, int j) {
    if (X(i) == X(j)) return Y(i) > Y(j) ? 1e18 : -1e18;
    return 1.0 * (Y(j) - Y(i)) / (X(j) - X(i));
}

int head = 1, tail = 1;
q[1] = 0; // 初始状态入队

for (int i = 1; i <= n; i++) {
    // 1. 队首出队：找到第一个斜率 > 当前斜率 k_i 的线段
    // 因为 k_i 单调递增，所以切点只会向右移
    while (head < tail && slope(q[head], q[head + 1]) <= 2 * A[i]) {
        head++;
    }
    
    // 2. 此时队首 q[head] 就是最优转移点
    int j = q[head];
    dp[i] = dp[j] + (A[i] - B[j]) * (A[i] - B[j]) + C[i];
    
    // 3. 队尾出队：加入新产生的状态 i，维护下凸壳
    while (head < tail && slope(q[tail - 1], q[tail]) >= slope(q[tail], i)) {
        tail--;
    }
    q[++tail] = i;
}
