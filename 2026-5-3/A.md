# T490400 20260503T1

## 题目描述

有一个 $1\times n$ 的棋盘，每个格子可以被染成黑色或者白色。一个合法的染色方案中两个黑格不应该离得太近，而且某个格子必须染成白色。

具体来说，有 $m$ 次询问，每次询问给定两个整数 $x,k$，表示任意两个黑格的间距都要大于等于 $k$，且第 $x$ 个格子必须染成白色。两个格子 $i,j$ 之间的间距定义为 $|i-j|$。

对于每次询问，请求出合法的染色方案数对 $998244353$ 取模的结果。

## 输入格式

第一行两个整数 $n,m$，表示棋盘大小和询问次数。

接下来 $m$ 行，每行两个整数 $x,k$ 表示询问参数。

## 输出格式

输出 $m$ 行，每行一个整数表示方案数对 $998244353$ 取模的结果。

## 输入输出样例 #1

### 输入 #1

```
3 4
1 2
2 2
3 2
2 3
```

### 输出 #1

```
3
4
3
3
```

## 说明/提示

### 样例解释

四组询问对应的合法方案分别有:
1. 白黑白，白白黑，白白白；
2. 黑白黑，黑白白，白白黑，白白白；
3. 白黑白，黑白白，白白白；
4. 黑白白，白白黑，白白白。

### 数据范围
$1\le n,m\le 10^5$，$1\le k,x\le n$。
