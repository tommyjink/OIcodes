## 题目描述

Pigeland 有 $n$ 只小猪。它们都非常擅长程序设计竞赛，第 $i$ 只小猪的能力值为 $a_i$。 如果有 $k$ 只小猪 $p_1,p_2,\cdots,p_k$ 组成一支队伍，那么这支队伍的能力值定义为：$a_{p_1} \& a_{p_2} \& a_{p_3} \& \cdots \& a_{p_k}$ 其中 $\&$ 表示按位与运算。

现在有若干场程序设计竞赛即将举行。Pigeland 每场比赛恰好派出一支队伍参加。对于第 $i$ 场比赛，只有编号在 $[l_i,r_i]$ 之间的小猪有时间参加比赛。然而，由于经费不足，必须从编号在 $[l_i,r_i]$ 之间的小猪中恰好去掉一只。其余所有在该区间内的小猪都会参加比赛。

教练 Pig-head 需要合理选择不参加比赛的小猪，使得最终队伍的能力值最大。但是，随着训练和参加比赛，小猪们的能力值可能会发生变化。作为 Pig-head 最好的朋友，你需要维护这些小猪的能力值，并处理接下来的 $q$ 个事件。

事件共有三种类型：

- 操作 $1$ `1 l r x` Pig-head 将编号在 $[l,r]$ 之间的每只小猪的能力值都与 $x$ 做按位与运算。也就是说，对于所有满足 $l \le i \le r$ 的 $i$，执行：$a_i \leftarrow a_i \& x$
- 操作 $2$`2 s x`Pig-head 将第 $s$ 只小猪的能力值直接修改为 $x$。也就是说：$a_s \leftarrow x$
- 操作 $3$`3 l r`Pig-head 询问：从编号在 $[l,r]$ 之间的小猪中选出所有小猪，但必须恰好去掉其中一只，剩下的小猪组成队伍，队伍能力值最大是多少。

## 输入格式

每个测试文件中只有一组测试数据。

第一行包含两个整数 $n,q$，表示小猪的数量和事件的数量。

第二行包含 $n$ 个整数：

$a_1,a_2,\cdots,a_n$

其中 $a_i$ 表示第 $i$ 只小猪的能力值。

接下来 $q$ 行，每行描述一个事件。

第 $i$ 个事件首先包含一个整数 $op_i$，表示事件类型，其中：

$op_i \in \{1,2,3\}$

- 如果 $op_i=1$，接下来输入三个整数 $l,r,x$；
- 如果 $op_i=2$，接下来输入两个整数 $s,x$；
- 如果 $op_i=3$，接下来输入两个整数 $l,r$。

## 输出格式

对于每个类型为 $3$ 的事件，输出一行一个整数，表示在对应区间内恰好去掉一只小猪后，队伍能力值的最大值。

## 输入输出样例 #1

### 输入 #1

```
5 9
7 7 7 6 7
3 1 5
2 1 3
3 1 5
3 1 3
1 1 2 3
3 1 3
2 2 8
3 1 3
3 1 2
```

### 输出 #1

```
7
6
7
3
3
8
```

## 说明/提示

初始数组为：$[7,7,7,6,7]$ 第一次询问区间 $[1,5]$，如果去掉第 $4$ 只小猪，剩下小猪的能力值为：$7 \& 7 \& 7 \& 7=7$ 因此答案为 $7$。

之后第 $1$ 只小猪被修改为 $3$，数组变为：$[3,7,7,6,7]$再次询问区间 $[1,5]$，最优结果为 $6$。

后续操作类似。

## 数据范围

对于所有测试点，均满足：$2 \le n \le 10^6$ $1 \le q \le 10^6$ $0 \le a_i < 2^{63}$

对于操作 $1$：$1 \le l \le r \le n$， $0 \le x < 2^{63}$

对于操作 $2$：$1 \le s \le n$， $0 \le x < 2^{63}$

对于操作 $3$：$1 \le l < r \le n$
