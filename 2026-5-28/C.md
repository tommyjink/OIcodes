# T3

时间限制：3.5 秒  
空间限制：256 兆字节

## 题目描述

给定一棵以 $1$ 为根、包含 $n$ 个顶点的树。每个顶点 $v$ 有一个权值 $p_v$，并且 $p$ 是 $0,1,\ldots,n-1$ 的一个排列。

设 $S_v$ 为从根 $1$ 到顶点 $v$ 的简单路径上所有顶点权值组成的集合。定义：

$f(v)$ 为集合 $S_v$ 中没有出现过的最小非负整数。

你至多可以执行一次如下操作，也可以不执行：

- 选择一个顶点 $v$，把 $p_v$ 修改为当前的 $f(v)$。

操作完成后，会基于新的权值重新计算所有顶点的 $f(v)$。请最大化：

$$\sum_{v=1}^{n} f(v)$$

输出这个最大值。

## 输入格式

第一行输入一个整数 $t$，表示测试用例数。

每个测试用例格式如下：

```
n
p_1 p_2 ... p_n
x_1 y_1
x_2 y_2
...
x_{n-1} y_{n-1}
```

其中每条边 $x_i,y_i$ 表示树上的一条无向边。树的根固定为 $1$。

## 输出格式

对每个测试用例输出一行，一个整数，表示执行至多一次操作后 $\sum f(v)$ 的最大值。

## 数据范围

- $1 \le t \le 2 \times 10^4$
- $1 \le n \le 2 \times 10^5$
- $0 \le p_i \le n-1$
- $p$ 是 $0,1,\ldots,n-1$ 的一个排列
- $1 \le x_i,y_i \le n$
- 输入保证边构成一棵树
- 所有测试用例的 $n$ 之和不超过 $2 \times 10^5$

## 样例说明

第一个测试用例中，不执行操作已经最优，答案为 $1$。

第二个测试用例中，初始时 $f(1)=0$、$f(2)=2$、$f(3)=0$。若选择顶点 $3$ 执行操作，把 $p_3$ 改为 $f(3)=0$，重新计算后可以得到最大总和 $4$。
