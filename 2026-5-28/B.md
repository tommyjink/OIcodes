# T2

时间限制：2 秒  
空间限制：256 兆字节

## 题目描述

给定一棵有 $n$ 个顶点的树。一次剪裁由三个互不相同的顶点 $a,b,c$ 决定，并要求 $a<b<c$。

对这三个点，考虑树上包含它们的最小连通子图。也就是说，这个子图由三点之间路径的并集组成。若这个最小连通子图包含的顶点数恰好为 $d$，则称三元组 $(a,b,c)$ 是合法的。

不同三元组视为不同方案。请统计合法三元组的数量。

## 输入格式

第一行输入一个整数 $t$，表示测试用例数。

每个测试用例首先输入两个整数 $n,d$，表示树的顶点数以及目标子图大小。

接下来 $n-1$ 行，每行输入两个整数 $u,v$，表示树上的一条无向边。

## 输出格式

对每个测试用例输出一行，一个整数，表示合法三元组数量。

## 数据范围

- $1 \le t \le 500$
- $3 \le d \le n \le 2000$
- $1 \le u,v \le n$
- $u \ne v$
- 输入保证每个测试用例给出的是一棵树
- 所有测试用例的 $n$ 之和不超过 $2000$

## 输入样例

```
3
4 3
1 2
3 1
4 1
5 5
1 2
2 4
2 3
5 1
7 7
1 2
1 3
2 4
2 5
3 6
3 7
```

## 输出样例

```
3
1
0
```

## 样例说明

第一个测试用例中，合法三元组为 $(1,2,3)$、$(1,2,4)$、$(1,3,4)$。三元组 $(2,3,4)$ 对应的最小连通子图大小为 $4$，不满足 $d=3$。

第二个测试用例中，只有三元组 $(3,4,5)$ 合法。

第三个测试用例中不存在合法三元组。
