# C

设同一个数字在序列中的最左和最右出现位置分别是 `L,R`，那么长度 `R-L` 的两个子数组

- `[L,R-1]`
- `[L+1,R]`

它们删去和加入的是同一个数字，所以一定互为排列。因此答案至少是某个数字的最远距离。

反过来可以证明：如果存在长度 `len` 的变位回声，那么答案一定不会超过某个数字的最远距离。所以题目就转成了：

- 给每种数字安排一个长度为 `lim+1` 的区间
- 这个数字的所有出现位置都必须落在自己的区间里
- 所有 `0` 都要被某个数字的区间覆盖
- 最小化 `lim`

于是可以二分答案 `lim`。

判定时：

- 若某个已有数字当前最远距离已经大于 `lim`，直接不合法
- 对于每个已有数字，可以算出它的区间左端点可选范围
- 把所有 `0` 从左到右处理，用一个小根堆维护当前能覆盖它的已有数字区间
- 优先选右端点限制最小的已有数字；如果没有，就新开一个原本没出现过的数字来覆盖这一段

这样判定和构造都是 `O(n log n)`。
