# signature 做法

先把一棵树的值看成一个关于若干变量的多项式。令 `x_i=g(i)`，则每个点的值是

```text
H(x)=1+sum H(y)*x_{s_y}
```

所以一棵树对应一个多项式。两棵树不可区分，当且仅当它们对应的多项式完全相同。因此题目就是问大小为 `n` 的有根无序二叉树能产生多少种不同多项式。

注意不能只用普通二叉树计数递推：

```text
F_n = F_{n-1} + sum F_i F_j + C(F_i+1,2)
```

这个在 `n=15` 会多算。原因是当两个儿子大小相同的时候，根的贡献是

```text
1+(P+Q)*x_i
```

不同的 `(P,Q)` 可能有相同的 `P+Q`，所以不能直接用组合数。

例如大小为 `7` 时就已经会出现两个不同签名相加后相同的情况，所以需要记录“若干个同大小签名相加”的种数。

## 状态

设

```text
dp[n][c]
```

表示从所有大小为 `n` 的签名里选出 `c` 个，可以得到多少种不同的和。

这里是可重集合意义下的和，因为同一个签名可以出现多次。最终答案是

```text
dp[n][1]
```

边界：

```text
dp[1][c]=1
```

因为大小为 `1` 的树只有叶子，签名恒为 `1`，选多少个和都只有一种。

## 转移

考虑 `c` 个大小为 `n` 的树的签名和。每个根的儿子情况独立分类。

一个大小为 `n` 的根，可能有：

1. 一个儿子，儿子大小为 `n-1`。
2. 两个儿子，大小分别为 `i,j`，满足 `i+j=n-1`，且 `i<=j`。

对 `c` 棵树一起看，每一种儿子大小组合会被使用若干次。设使用次数是 `t`，那么会贡献一项生成函数系数。

### 一个儿子

如果有 `t` 棵树使用唯一儿子大小 `n-1`，那么可行和的种数是

```text
dp[n-1][t]
```

因为这些树贡献的是 `t` 个大小为 `n-1` 的签名之和，再整体乘上变量 `x_{n-1}`，变量不同不会造成新的合并。

### 两个儿子，大小不同

若儿子大小为 `i,j`，且 `i<j`，使用了 `t` 次，则左边大小 `i` 的签名和、右边大小 `j` 的签名和互相独立：

```text
dp[i][t] * dp[j][t]
```

### 两个儿子，大小相同

若两个儿子大小都为 `i`，使用了 `t` 次，则总共会出现 `2t` 个大小为 `i` 的儿子签名，所以种数是

```text
dp[i][2t]
```

这正好解决了 `P+Q` 可能撞的问题。

## 生成函数形式

对固定的 `n`，维护一个多项式 `f`，其中 `f[c]` 表示当前考虑完一些根类型后，构造 `c` 棵大小为 `n` 的树的签名和有多少种。

初始：

```text
f[0]=1
```

每加入一种根类型，就卷积一次。

唯一儿子类型的生成函数：

```text
G(t)=sum dp[n-1][c] t^c
```

两个儿子大小不同 `i<j`：

```text
G(t)=sum dp[i][c]*dp[j][c] t^c
```

两个儿子大小相同 `i=i`：

```text
G(t)=sum dp[i][2c] t^c
```

所有根类型乘起来后，得到的系数就是 `dp[n][c]`。

代码里 `lim=mx/n`，因为最多只会查询总大小不超过 `mx` 的状态，所以大小为 `n` 的东西最多取 `mx/n` 个。

## 复杂度

对每个 `n`，只算到 `mx/n` 项，并且每次乘法也是截断卷积。总复杂度大约是

```text
O(n^2 log n)
```

实际 `n<=3000` 很稳。

空间是

```text
O(n^2)
```

## 模数

题目里的 `p` 不一定是质数，所以不能用逆元。这个做法全程只有加法和乘法，不需要除法，因此对任意 `p` 都成立。

如果多组询问模数相同，就一起处理到该模数下最大的 `n`，再回答这些询问。
