## 题目描述

在 KMP 算法中，`next` 数组（也称为 LPS 数组，即 *Longest Prefix Suffix*，或失配函数）是一个核心概念。

给定一个长度为 $n$ 的字符串 $S=s_1s_2\cdots s_n$，它的 `next` 数组 `next[1..n]` 定义为：`next[i]` 表示子串 $S[1..i]$ 的最长相等真前缀与真后缀的长度，其中特别规定 `next[1]=0`。

形式化地，有：

$$
next[i]=\max_{k=0,\ldots,i-1}\{\,k \mid S[1..k]=S[i-k+1..i]\,\}
$$

其中，$S[l..r]$ 表示字符串 $S$ 的第 $l$ 个字符到第 $r$ 个字符组成的子串。

约定对于任意 $1 \le i \le n$，$S[1..0]=S[i+1..i]$，二者都表示空串。


现在给定一个长度为 $n$ 的数组 $A[1..n]$。你需要计算：有多少个长度为 $n$、字符集为 $\Sigma$ 的字符串 $S$，其 `next` 数组 **恰好等于** 给定数组 $A$。

已知字符集大小为 $m$。答案对 $998244353$ 取模后输出。

## 输入格式

输入包含多组测试数据。

第一行包含一个整数 $T$（$1 \le T \le 10^5$），表示测试数据组数。

对于每组测试数据：

- 第一行包含两个整数 $n,m$（$2 \le n \le 10^5,\ 1 \le m \le 10^6$），分别表示数组长度和字符集大小。
- 第二行包含 $n$ 个整数 $A_1,A_2,\ldots,A_n$，表示给定的数组 $A$。保证对所有 $1 \le i \le n$，都有：
  
  $$
  0 \le A_i \le i-1
  $$

保证所有测试数据中，$n$ 的总和不超过 $5\times 10^5$。

## 输出格式

对于每组测试数据，输出一行一个整数，表示满足条件的字符串个数，对 $998244353$ 取模。

## 输入输出样例 #1

### 输入 #1

```

7 3

```

### 输出 #1

```

```
