# T748399 20260404T3

## 题目描述

给定一个只包含小写字母的字符串集合 $\{s_i\}$，你需要从中选出若干个字符串，并选择一个合适的顺序将它们拼接成一个新字符串，记为 $S$。

出题人不希望 $S$ 中存在子序列 `luolikong`，即不存在一个位置集合 $\{pos_i\}$，满足：

1. 集合大小为 $9$，且对于所有 $1 \le i \le 9$，有 $1 \le pos_i \le |S|$。
2. 对于所有 $1 \le i \le 8$，有 $pos_i < pos_{i+1}$。
3. 令长度为 $9$ 的字符串 $t$ 满足 $t_i = S_{pos_i}$，则有 $t = \texttt{luolikong}$。

你只需要计算可能得到的 $S$ 的最大长度。

## 输入格式

第一行包含一个整数 $n$（$1 \le n \le 5000$），表示集合 $\{s_i\}$ 的大小。

接下来的 $n$ 行，每行包含一个字符串 $s_i$，满足：

- $1 \le |s_i| \le 5 \times 10^5$
- $\sum |s_i| \le 5 \times 10^5$

## 输出格式

输出一行一个整数，表示可能的 $S$ 的最大长度。

## 输入输出样例 #1

### 输入 #1

```
5
zhongzhikong
luo
likelisi
kluikong
likuong
```

### 输出 #1

```
31
```

## 说明/提示

一种合法的拼接方案为：

```text
zhongzhikong kluikong luo likelisi
```

容易证明，不存在另一种拼接方案，使得字符串长度大于 $31$ 且不含子序列 `luolikong`。
