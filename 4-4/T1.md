# T748373 20260404T1

## 题目描述

给定一个由 $0$ 和 $1$ 组成的 $N \times M$ 矩阵 $A=(A_{i,j})$（$1 \le i \le N,\ 1 \le j \le M$）。

所有此类矩阵一共有 $2^{NM}$ 个。请计算其中满足以下条件的矩阵个数，并对 $998244353$ 取模输出。

对于每个 $k=1,2,\ldots,K$，都需要同时满足：

1. $\sum_{i=1}^{x_k}\sum_{j=1}^{y_k} A_{i,j}$ 是奇数；
2. $\sum_{i=x_k+1}^{N}\sum_{j=y_k+1}^{M} A_{i,j}$ 是奇数。

## 输入格式

输入格式如下：

```text
N M
K
x1 y1
x2 y2
...
xK yK
```

## 输出格式

输出一个整数，表示答案。

## 输入输出样例 #1

### 输入 #1

```
3 4
2
2 2
1 3
```

### 输出 #1

```
256
```

## 输入输出样例 #2

### 输入 #2

```
76 38
4
7 6
3 8
20 26
3 28
```

### 输出 #2

```
361562686
```

## 说明/提示

- $2 \le N, M \le 10^9$
- $1 \le K \le 3 \times 10^5$
- $1 \le x_i < N$（$1 \le i \le K$）
- $1 \le y_i < M$（$1 \le i \le K$）
- 对任意 $i \ne j$，$(x_i, y_i) \ne (x_j, y_j)$
- 输入中的所有值均为整数
