# T760449 20260512T3

## 题目描述

给定一个长度为 $N$ 的整数序列：

$$
A=(A_1,A_2,\ldots,A_N)
$$

你可以自由地重新排列序列 $A$。

请你求出重新排列后，下式能够取得的最大值：

$$
\sum_{i=1}^{N-1} \left((A_{i+1}-A_i) \bmod K\right)
$$

其中，$x \bmod K$ 表示满足以下条件的整数 $y$：

$$
0 \le y < K
$$

并且 $x-y$ 是 $K$ 的倍数。

例如：

$$
-3 \bmod 8 = 5
$$

$$
9 \bmod 6 = 3
$$

## 输入格式

输入从标准输入给出，格式如下：

```text
N K
A_1 A_2 ... A_N
```

## 输出格式

输出答案。

## 输入输出样例 #1

### 输入 #1

```
3 4
0 1 2
```

### 输出 #1

```
6
```

## 输入输出样例 #2

### 输入 #2

```
7 123
11 34 56 0 32 100 78
```

### 输出 #2

```
638
```

## 说明/提示

记 $m$ 为序列中某个数出现次数的最大值，记

$$
S=\{x\mid x\text{ 在序列中出现了 }m\text{ 次}\}
$$

| 子任务 | 分值 | 限制条件 |
| --- | ---: | --- |
| $2$ | $5$ | $N \le 20$ |
| $3$ | $10$ | 所有 $A_i$ 两两不同 |
| $4$ | $15$ | $\|S\|=1$|
| $5$ | $15$ | $ \|S\| \le 2$ |
| $6$ | $20$ | $ \|S\| \le 2000$ |
| $7$ | $35$ | 无特殊限制 |
