## 题目描述

欢迎来到 Mr. Ant Tenna 的电视时间！

在这一轮游戏中，你有 $n$ 个水桶。第 $i$ 个水桶的最大容量为 $v_i$。

游戏开始时，所有水桶都会被装满水。你的任务是在接下来的 $t$ 秒内尽可能多地保留水量。

但是，这些水桶都是坏的！第 $i$ 个水桶的漏水速度为 $l_i$，表示游戏开始后每过 $1$ 秒，第 $i$ 个水桶就会漏掉 $l_i$ 体积的水。

在游戏开始之前，你可以将任意数量的水桶合并成一个水桶。合并后的水桶具有如下性质：

- 容量等于被合并水桶中的最大容量；
- 漏水速度等于被合并水桶中的最小漏水速度。

你可以进行任意多次合并操作，但所有合并都必须在装水之前完成。

Tenna 会提出 $q$ 个询问，其中第 $i$ 个询问给出一个时间限制 $t_i$。

对于每个 $1 \le i \le q$，请计算经过 $t_i$ 秒后，最多能够保留的总水量。

注意：每个询问都是相互独立的。

## 输入格式

输入包含多组测试数据。

第一行包含一个整数 $T$，表示测试数据组数。

对于每组测试数据：

第一行包含一个整数 $n$，表示水桶数量。

第二行包含 $n$ 个整数 $v_1, v_2, \dots, v_n$，其中 $v_i$ 表示第 $i$ 个水桶的容量。

第三行包含 $n$ 个整数 $l_1, l_2, \dots, l_n$，其中 $l_i$ 表示第 $i$ 个水桶的漏水速度。

第四行包含一个整数 $q$，表示询问数量。

第五行包含 $q$ 个整数 $t_1, t_2, \dots, t_q$，其中 $t_i$ 表示第 $i$ 个询问的时间限制。

## 输出格式

对于每组测试数据，输出一行，包含 $q$ 个整数。

其中第 $i$ 个整数表示经过 $t_i$ 秒后最多能够保留的总水量。

相邻整数之间用一个空格隔开。

## 输入输出样例 #1

### 输入 #1

```
2
4

2 1 3 2
3
3 1 2
4
19 47 21 13

5

```

### 输出 #1

```

```

## 说明/提示

- $1 \le T \le 5 \times 10^4$
- $1 \le n \le 2 \times 10^5$
- $1 \le v_i \le 4 \times 10^{13}$
- $0 \le l_i \le 10^9$
- $1 \le q \le 2 \times 10^5$
- $0 \le t_i \le 10^9$

保证所有测试数据中：

- $\sum n \le 2 \times 10^5$
- $\sum q \le 2 \times 10^5$
