## A. 简单数学题

### 题目信息

时间限制：`1s`

空间限制：`256 MB`

输入文件：`variance.in`

输出文件：`variance.out`

### 题目描述
数学老师今天布置了一道简单的数学题，锻炼大家的计算能力，给出一个长度为 $n$ 的数列 $A_1, A_2, \cdots, A_n$, 请求出该数列每个前缀的和、平均值和方差。

即，对于每个 $i\in[1, n]$ 输出:
1. 和: $\sum_{j=1}^i A_j=A_1+A_2+\cdots+A_i$
2. 平均数: $B_i=\frac{1}{i} \sum_{j=1}^i A_j=\frac{A_1+A_2+\cdots+A_i}{i}$
3. 方差: $\frac{1}{i} \sum_{j=1}^i\left(A_j-B_i\right)^2=\frac{\left(A_1-B_i\right)^2+\left(A_2-B_i\right)^2+\cdots\left(A_i-B_i\right)^2}{i}$

注意，因为数学老师都讨厌小数，所以若输出结果中某个数不是整数，**则以最简分数形式输出。**

保证所有的 $A_i>0$。


### 输入格式
第一行一个整数 $n$，表示给出的数列的长度。

接下来一行 $n$ 个数表示数列 $A_i$。

### 输出格式
输出共 $n$ 行，每行三个数：

+ 第 $i$ 行的三个数依次表示 $A_1, \cdots A_i$ 的和、平均数和方差。

**注意：** 如果和、平均数或方差的值为整数，则以整数的形式输出；否则，请以 $\mathrm{a}/\mathrm{b}$ 的形式输出最简分数，其中 $a$ 为非负整数，$b$ 为正整数，且 $a$ 和 $b$ 互质。可以参考样例输出。

### 样例
#### 样例输入 1
```text
5
1 7 2 3 8
```

#### 样例输出 1
```text
1 1 0
8 4 9
10 10/3 62/9
13 13/4 83/16
21 21/5 194/25
```

### 数据范围
$1 \leq n \leq 10^5, 1 \leq A_i \leq 10^3$ 

+ subtask1(30pts): $n \leq 10, A_i \leq 10$
+ subtask2(40pts): $n \leq 5000$
+ subtask3(30pts): 无限制

## T2 简单算法题

### 题目信息

时间限制:  `1s`

空间限制: `256M`

输入文件: `algorithm.in`

输出文件: `algorithm.out`

### 题目描述
基于括号序列可以出许多有趣的简单算法题，一个合法括号序列的定义如下：

1. `()` 是合法的。
2. 如果括号序列 `X` 是合法的，那么括号序列 `(X)` 是合法的。
3. 如果括号序列 `X` 和 `Y` 都是合法的，那么括号序列 `XY` 是合法的

例如，括号序列 `()()(())` 是合法的，`()))()((` 是不合法的。

定义一个生成括号序列的操作流程：

+ 给定长度为 $n$ 的整数序列 $c_0, c_1, \ldots, c_{n-1}$，依次执行 $n$ 次操作构建括号序列。
+ 初始时括号序列为空，第 $i+1$ 次操作时，若 $i$ 为偶数，则往当前括号序列末尾加人 $c_i$ 个左括号；否则就往当前括号序列末尾加 $c_i$ 个右括号。

例如，序列 `3211` 构建出来的括号序列为 `((())()`。

注意，按照上述流程构建出来的括号序列 $\mathrm{S}$ 不一定是合法的，但是 $\mathrm{S}$ 的子串有可能是合法括号序列，请求出 $\mathrm{S}$ 的非空子串是合法括号序列的数量。

即求有多少个区间 $[l, r](1 \leq l \leq r \leq|S|)$， 使得 $S[l, r]$ 是合法括号序列。

### 输入格式
本题采用如下方式生成输入数据：

输入仅一行，8 个整数 $n, x, y, z, m_0, m_1, c_0, c_1$。

对于 $i>1$，$c_i=\left(c_{i-1} \times x+c_{i-2} \times y+z\right) \bmod M_i+1$，其中当 $i$ 为偶数时 $M_i=m_0$，当 $i$ 为奇数时 $M_i=m_1$。

整数序列 $c$ 的含义如题所述。

### 输出格式
一行一个整数表示 $\mathrm{S}$ 中合法的非空括号子串的数量。

### 样例
#### 样例输入 1
```text
10 686962104 149902149 5232363 10 4 7 3
```

#### 样例输出 1
```text
15
```

### 数据范围
$\begin{aligned} & 1 \leq n \leq 10^7, 0 \leq x, y, z \leq 10^9, 1 \leq c_0 \leq m_0 \leq 10^9, 1 \leq c_1 \leq m_1 \leq 10^9 \\ & \text { subtask } 1(8 p t s): n \leq 20, \max \left\{m_0, m_1\right\} \leq 500 \\ & \operatorname{subtask} 2(16 p t s): n \leq 5000, \max \left\{m_0, m_1\right\} \leq 4000 \\ & \text { subtask } 3(8 p t s): n \leq 20 \\ & \text { subtask } 4(16 p t s): n \leq 5000 \\ & \text { subtask } 5(8 p t s): n \leq 10^6, m_1=1 \\ & \text { subtask } 6(28 p t s): n \leq 10^6 \\ & \text { subtask } 7(16 p t s): \text { 无限制 }\end{aligned}$

## T3 子序列计数

### 题目信息

时间限制:  `1s`

空间限制: `256M`

输入文件: `count.in`

输出文件: `count.out`

### 题目描述
众所周知，一个长度为 $n$ 的序列共有 $2^n-1$ 个不同的非空子序列，现给出一个长度为 $n$ 的序列 $a_1, a_2, \dots, a_n$，其中 $0 \leq a_i<2^m$，且 $a_i$ 互不相同

定义 $a$ 的一个子序列 $p=a_{p_1}a_{p_2}\dots a_{p_k}$ 是合法的，当且仅当：

1. $1\leq p_1 < p_2 < \dots < p_k \leq n$
2. $\forall 1 \leq i \leq k-3, a_{p_i} \oplus a_{p_{i+1}} \oplus a_{p_{i+2}} \oplus a_{p_{i+3}}\neq s$，其中 $\oplus$ 表示异或

请问对于 $a$，有多少个合法的非空子序列？请输出答案 $\bmod\ 998244353$ 之后的结果即可

注：长度小于 4 的非空子序列都是合法的。

### 输入格式
第一行三个正整数 $n, m, s$，其中 $n$ 表示序列 $a$ 的长度，$m$ 表示 $a_i$ 的范围，$s$ 的含义如题面所示

接下来一行 $n$ 个**互不相同**的非负整数 $a_i$

### 输出格式
一行一个整数表示答案 $\bmod\ 998244353$ 之后的结果

### 样例
#### 样例输入 1
```text
5 3 3
2 3 4 7 6
```

#### 样例输出 1
```text
30
```

### 数据范围
$\begin{aligned} & 1 \leq n \leq 4000,1 \leq m \leq 12,0 \leq a_i, s<2^m \\ & \text { subtask } 1(15 p t s): n \leq 10, m \leq 4 \\ & \text { subtask2(20pts) : } n \leq 60, m \leq 6 \\ & \text { subtask } 3(25 p t s): n \leq 200, m \leq 8 \\ & \text { subtask } 4(25 p t s): n \leq 1000, m \leq 10 \\ & \text { subtask } 5(15 p t s): n \leq 4000, m \leq 12\end{aligned}$

## T4 邮递员

### 题目信息

时间限制：`2s`

空间限制：`256 MB`

输入文件：`courier.in`

输出文件：`courier.out`

### 题目描述
京郊小镇可以用 $n \times m$ 的网格图描述，第 $i$ 行第 $j$ 列的格子记为 $(i, j), 1 \le i \le n, 1 \le j \le m$。

京郊小镇只有一位邮递员 g，g 每天需要经过小镇的每个格子至少一次，因为每个格子上都有等待收信的居民。京郊小镇邮局的位置在 $(x_s, y_s)$，这也是 g 每天开始送信的起点。g 今天想吃位于 $(x_t, y_t)$ 的麻辣香锅，因为这家香锅经常需要排队，所以 g 想尽可能快地结束今天的工作抵达饭店。

每一时刻，g 可以进行以下四种移动之一：

+ U：从当前位置 $(x, y)$ 移动至 $(x,y-1)$。
+ D：从当前位置 $(x, y)$ 移动至 $(x,y+1)$。
+ L：从当前位置 $(x, y)$ 移动至 $(x-1,y)$。
+ R：从当前位置 $(x, y)$ 移动至 $(x+1,y)$。

京郊小镇任意一对相邻网格间的移动耗时都是固定的，为了让 g 尽早吃到麻辣香锅，需要构造一个长度为 $n\cdot m-1$ 的满足以下要求的移动序列，使得：

+ 任意时刻，g 所在的位置 $(x, y)$ 没有超出京郊小镇，即 $1 \le x \le n$ 且 $1 \le y \le m$。
+ 今天工作的起点是 $(x_s, y_s)$。
+ 在今天的工作过程中，g 经过了每个格子**恰好一次**。
+ 今天工作的终点是 $(x_t, y_t)$。


### 输入格式
输入只有一行，包含六个整数 $n, m, x_s, y_s, x_t, y_t$，含义如题面所示。

### 输出格式
输出一行，包含一个长度恰好为 $n \cdot m - 1$ 的字符串，描述任意一种可行的移动序列。

**数据保证一定存在一组合法的解。**

### 样例
#### 样例输入 1

```text
5 5 1 1 5 5
```

#### 样例输出 1

```text
RRRRDDDLLLURRULLLDDDRRRR
```

#### 样例输入 2

```text
4 6 2 2 1 4
```

#### 样例输出 2

```text
RRULLLDDRRRDDDLLLURRULL
```
