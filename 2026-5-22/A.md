# T763205 20260522T1

## 题目描述

你正在玩一款塔防游戏，可以在一个 $n \times m$ 的网格中建造两种防御塔。

每种防御塔都有基础每秒伤害：A 塔的基础每秒伤害为 $d_A$，B 塔的基础每秒伤害为 $d_B$。由于后续关卡中的怪物会不断变强，你希望最大化所有防御塔的总每秒伤害。

此外，每种防御塔都有各自的特殊效果：

- 群体效应（A 塔）：对每个 A 塔，它每有一个上下左右相邻的 A 塔，每秒伤害就增加 $1$。该效果可以叠加。
- 孤立效应（B 塔）：对每个 B 塔，它每有一个上下左右相邻的 B 塔，每秒伤害就减少 $1$。该效果可以叠加，但每秒伤害不会低于 $0$。

有些网格单元是障碍，记为 `#`，不能建造防御塔。其余单元为空地，记为 `.`，每个空地单元中至多可以建造一个防御塔，也可以不建造防御塔。

你需要安排防御塔的建造位置和类型，使得所有防御塔的总每秒伤害最大。

## 输入格式

第一行包含四个整数 $n,m,d_A,d_B$，满足：

$$
1 \le n,m \le 2000,\quad 1 \le d_A,d_B \le 10^9
$$

接下来 $n$ 行，每行包含 $m$ 个字符，字符只可能为 `.` 或 `#`。其中 `.` 表示空地，`#` 表示障碍。

## 输出格式

第一行输出最大总每秒伤害。

接下来输出 $n$ 行，每行包含 $m$ 个字符，表示建造防御塔后的网格。其中：

- `A` 表示 A 塔；
- `B` 表示 B 塔；
- 其它符号应与输入保持一致。

## 输入输出样例 #1

### 输入 #1

```
3 3 2 8
...
#..
...
```

### 输出 #1

```
46
BBB
#AA
BBB
```

## 说明/提示

各个防御塔的每秒伤害如下：

```text
7 6 7
# 3 3
7 6 7
```
