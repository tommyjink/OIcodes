## 题目描述

有 $n$ 堆石子，初始时每一堆都恰好有 $1$ 颗石子。

你可以进行若干次操作。每次操作选择一个位置 $p$，其中 $1 \le p \le n$，然后按如下规则移动石子：

- 若 $p = 1$，则从第 $2$ 堆取出 $1$ 颗石子，放入第 $1$ 堆。操作前第 $2$ 堆必须至少有 $1$ 颗石子。
- 若 $p = n$，则从第 $n-1$ 堆取出 $1$ 颗石子，放入第 $n$ 堆。操作前第 $n-1$ 堆必须至少有 $1$ 颗石子。
- 若 $2 \le p \le n-1$，则从第 $p-1$ 堆和第 $p+1$ 堆各取出 $1$ 颗石子，放入第 $p$ 堆。操作前第 $p-1$ 堆和第 $p+1$ 堆都必须至少有 $1$ 颗石子。

给定目标状态 $a_1,a_2,\ldots,a_n$。你需要求出最少需要多少次操作，才能使得对于所有 $1 \le i \le n$，第 $i$ 堆恰好有 $a_i$ 颗石子。

可以证明，当 $\sum a_i = n$ 时，一定存在一个有限的合法操作序列。

另外，在某些测试中，你还需要输出具体的操作序列。

## 输入格式

第一行包含两个整数 $n, typ$，其中 $3 \le n \le 2 \times 10^5$，$typ \in \{0,1\}$。

$typ$ 表示是否需要输出操作序列。

第二行包含 $n$ 个整数，表示 $a_i$。

保证 $0 \le a_i \le n$，且 $\sum a_i = n$。

## 输出格式

若 $typ = 0$，输出一个整数，表示最少操作次数。

若 $typ = 1$，需要输出两行：

- 第一行输出一个整数 $ans$，表示最少操作次数。
- 第二行输出 $ans$ 个整数，其中第 $i$ 个整数表示第 $i$ 次操作选择的位置。

保证当 $typ = 1$ 时，$ans \le 2 \times 10^5$。

## 输入输出样例 #1

### 输入 #1

```
5 1
0 2 1 2 0
```

### 输出 #1

```
3
3 2 4
```

## 输入输出样例 #2

### 输入 #2

```
10 0
0 0 5 2 2 1 0 0 0 0
```

### 输出 #2

```
103
```

## 说明/提示

- $3 \le n \le 2 \times 10^5$
- $typ \in \{0,1\}$
- $0 \le a_i \le n$
- $\sum a_i = n$
- 当 $typ = 1$ 时，最少操作次数 $ans \le 2 \times 10^5$

令

$$
b_i=\sum_{j=1}^i a_j.
$$

| 子任务编号 | 分值 | 附加限制 |
| --- | ---: | --- |
| $1$ | $8$ | $typ = 0$，$n \le 8$ |
| $2$ | $12$ | $typ = 0$，$n \le 200$ |
| $3$ | $15$ | $typ = 0$，$n \le 2000$，且对所有 $1 \le i < n$，都有 $b_i \le i$ |
| $4$ | $20$ | $typ = 0$，且对所有 $1 \le i < n$，都有 $b_i \le i$ |
| $5$ | $20$ | $typ = 0$ |
| $6$ | $10$ | $typ = 1$，$n \le 2000$ |
| $7$ | $15$ | $typ = 1$ |

所有子任务均满足全局限制；对于 $typ = 1$ 的子任务，仍保证 $ans \le 2 \times 10^5$。
